# Calculator App

A simple Calculator application built using **React** and **Tailwind CSS**. This app allows users to perform basic arithmetic operations such as addition, subtraction, multiplication, and division.

## Features

- ➕ Addition
- ➖ Subtraction
- ✖️ Multiplication
- ➗ Division
- 🎨 Styled with Tailwind CSS

## Installation & Setup

### Prerequisites

- Node.js installed
- npm or yarn package manager

### Steps

```bash
# Clone this repository
git clone https://github.com/jsaurabh1906/React-Projects.git
cd React-Projects
cd 03-Basic-Calculator

# Install dependencies
npm install

# Start the development server
npm run dev
```

## Technologies Used

- ⚛️ React
- 🎨 Tailwind CSS
- 🛠️ JavaScript (ES6+)

## Usage

1.  Enter numbers using the input field.
2.  Click the respective operation button ( +, -, ×, ÷ ).
3.  View the calculated result instantly.
