# Project: Expense Tracker

## Description:

This is a simple expense tracker application built using React and Tailwind CSS. It allows users to track their expenses by adding them.

## Built With:

- React
- Tailwind CSS

## Features:

- Add expenses
- View expenses

## 📦 Installation & Setup

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/jsaurabh1906/React-Projects.git
cd React-Projects
cd 09-Expense-Tracker
```

### 2️⃣ Install Dependencies

```bash
npm install # OR yarn install
```

### 3️⃣ Start the Development Server

```bash
npm run dev # OR yarn dev
```

## Usage

1️⃣ Enter the description of the expense
2️⃣ Enter the amount of the income/expense. (Use Negative values to add expense)
3️⃣ Click the "Add Transaction" button to add the income or expense to the list and you can see the Balance.
4️⃣ The income / expense will be added to the list and displayed with the description and amount.
5️⃣ You can view all the expenses (in light red bg) and incomes (in light green bg) added by you.
