# To-Do List App

A simple To-Do List application built using **React** and **Tailwind CSS**. This app allows users to add, edit, and delete tasks efficiently.

## Features

- ✅ Add new tasks
- ✏️ Edit existing tasks
- ❌ Delete tasks
- 🎨 Styled with Tailwind CSS

## Installation & Setup

### Prerequisites

- Node.js installed
- npm or yarn package manager

### Steps

```bash
# Clone this repository
git clone https://github.com/jsaurabh1906/React-Projects.git
cd React-Projects
cd 02-TodoApp

# Install dependencies
npm install

# Start the development server
npm run dev
```

## Technologies Used

- ⚛️ React
- 🎨 Tailwind CSS
- 🛠️ JavaScript (ES6+)

## Usage

1.  Enter a task in the input field.
2.  Click the **Add** button to add it to the list.
3.  Click **Edit** to modify a task.
4.  Click **Delete** to remove a task from the list.
