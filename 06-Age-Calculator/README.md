# Age Calculator

This is a simple age calculator app built with React and Tailwind CSS.

## Features

- 📅 Calculate age based on date of birth
- 📊 Display age in years, months, and days
- 📱 Responsive design for different screen sizes

## Installation and Setup

### Prerequisites

- Node.js
- npm

### Steps

```bash
# Clone this repository
git clone https://github.com/jsaurabh1906/React-Projects.git
cd React-Projects
cd 06-Age-Calculator

# Install dependencies
npm install

# Start the development server
npm run dev
```

## Technologies Used

- ⚛️ React
- 🎨 Tailwind CSS
- 🛠️ JavaScript (ES6+)

## Usage

- 1. Enter Your Birth date in the input field.
- 2. Click the "Calculate Age" button.
- 3. The app will display your age in years, months, and days.
