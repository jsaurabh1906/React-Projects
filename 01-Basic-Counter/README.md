# Counter App

## Description

A simple React counter application that allows users to increment, decrement, and reset a counter.

## Features

- Increment the counter
- Decrement the counter
- Reset the counter

## Technologies Used

- React
- Tailwind CSS

## Installation

1.  git clone https://github.com/jsaurabh1906/React-Projects.git
2.  cd React-Projects
3.  cd 01-Basic-Counter
4.  npm install
5.  npm run dev

## Usage

- Click **Increment** to increase the counter.
- Click **Decrement** to decrease the counter.
- Click **Reset** to set the counter back to zero.
