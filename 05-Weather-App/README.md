# Weather App

This is a simple weather app built using React and Tailwind CSS. It allows users to search for weather information by city name and displays the current temperature, humidity, and wind speed and the forecast for the next 5 days.

## Features

- Search for weather information by city name
- Display current temperature, humidity, and wind speed
- Display 5-day forecast with daily high and low temperatures
- Different background gradients based on weather conditions

## Installation

To run the app, you will need to have Node.js and npm installed on your computer. Clone the repository and run the following commands:

### Steps

```bash
# Clone this repository
git clone https://github.com/jsaurabh1906/React-Projects.git
cd React-Projects
cd 05-Weather-App

# Install dependencies
npm install

# Add Environment Variables in .env file
# Weather API Key from OpenWeatherMap API
VITE_WEATHER_API_KEY=your_api_key




# Start the development server
npm run dev
```

## Technologies Used

- ⚛️ React
- 🎨 Tailwind CSS
- 🛠️ JavaScript (ES6+)
- 🌐 Open Weather Api

## Usage

To use the app, simply enter a city name in the search bar. The app will fetch the weather data from the OpenWeatherMap API and display it on the page.
