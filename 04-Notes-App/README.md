# Notes App

A simple Notes App built using **React** and **Tailwind CSS**. This app allows users to create, edit, and delete notes.

## Features

- 📝 Create new notes
- ✏️ Edit existing notes
- 🗑️ Delete notes
- 🎨 Styled with Tailwind CSS

## Installation & Setup

### Prerequisites

- Node.js installed
- npm or yarn package manager

### Steps

```bash
# Clone this repository
git clone https://github.com/jsaurabh1906/React-Projects.git
cd React-Projects
cd 02-Notes-App

# Install dependencies
npm install

# Start the development server
npm run dev
```

## Technologies Used

- ⚛️ React
- 🎨 Tailwind CSS
- 🛠️ JavaScript (ES6+)

## Usage

- 1. Add some Note by entering the title and content in the input fields.
- 2. Click on the "Add Note" (+ icon) button to add the note.
- 3. You can edit the note by clicking on the "Edit" (✏️ icon) button.
- 4. You can delete the note by clicking on the "Delete" ( 🗑️ icon) button.
