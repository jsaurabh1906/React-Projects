# 📌 QR Code Generator

A simple **QR Code Generator** built with **React** and **Tailwind CSS** that allows users to generate QR codes from text or URLs.

---

## 🚀 Features

✅ Generate QR codes instantly from text or URLs.  
✅ Responsive and mobile-friendly UI.  
✅ Clear error handling for empty input.  
✅ Smooth user experience with interactive styling.

---

## 🛠️ Tech Stack

- **React** ⚛️
- **Tailwind CSS** 🎨
- **qrcode.react** 📷

---

---

## 📦 Installation & Setup

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/jsaurabh1906/React-Projects.git
cd React-Projects
cd 08-QR-Code-Generator
```

### 2️⃣ Install Dependencies

```bash
npm install # OR yarn install
```

### 3️⃣ Start the Development Server

```bash
npm run dev # OR yarn dev
```

---

## 🖥️ Usage

1️⃣ Enter a **text or URL** in the input field.  
2️⃣ Click **Generate QR Code** 🔄.  
3️⃣ The QR code will be displayed below.
